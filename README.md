# Ubuntu

也许是最流行的`Linux`，兼容性很好，对用户非常亲切，用起来比较容易。尝试用了国内的`UOS`，感觉就是从这里抄写的比较多。

缺点：无论如何，其鼠标相应能力都不如`Debain`的表现，虽然它俩师出同门。但是最新版的 `Ubuntu` 好像是改进了不少。

另外，尝试了 `Xbuntu` ，是 `Ubuntu` 的轻量级版本，用起来也不错。

### Ubuntu桌面环境（GUI）的选择

在安装 Debian 的最后阶段，系统会让你勾选安装哪种桌面环境。不同的桌面环境对内存的消耗差别很大：

| **桌面环境**    | **512MB - 1GB 内存** | **推荐度（针对4GB内存）** | **特点**                                                  |
| --------------- | -------------------- | ------------------------- | --------------------------------------------------------- |
| **XFCE / LXQt** | 约 400MB - 600MB     | ⭐️⭐️⭐️⭐️⭐️ （最推荐）          | 极度轻量，省下来的内存可以全留给浏览器和应用。            |
| **MATE**        | 约 600MB - 700MB     | ⭐️⭐️⭐️⭐️                      | 传承经典，经典 Windows 布局，资源占用低。                 |
| **KDE Plasma**  | 约 800MB - 1GB       | ⭐️⭐️⭐️⭐️                      | 现代、华丽，近年优化极好，4GB 内存完全带得动。            |
| **GNOME**       | 约 1GB - 1.2GB       | ⭐️⭐️⭐️                       | Debian 默认桌面，功能全面但相对吃内存，不建议开太多后台。 |

### Ubuntu官方衍生版

Ubuntu 官方推出了几款更换了轻量桌面的**官方衍生版（Flavours）**，它们和 Ubuntu 共享同一个软件源，但内存占用暴降：

- **Xubuntu (搭载 XFCE 桌面)：** 开机内存占用大约 **500MB - 600MB**。界面清爽传统，速度极快，是 4GB 内存老电脑的绝佳选择。
- **Lubuntu (搭载 LXQt 桌面)：** 比 Xubuntu 还要轻量，开机约 **400MB** 左右，把省内存做到了极致。
- **Ubuntu MATE (搭载 MATE 桌面)：** 占用大约 **600MB - 700MB**，非常类似当年经典的 Ubuntu 10.04 界面，操作顺手。

### 总结

- 如果你想追求**极度的纯净、稳定和低资源占用**，用 **Debian + XFCE** 是完美组合，开机可能只要 400MB 不到。
- 如果你更喜欢 **Ubuntu 的开箱即用和广泛的社区支持**，直接下载 **Xubuntu** 镜像安装，能让你在 4GB 内存上找回飞速的感觉。

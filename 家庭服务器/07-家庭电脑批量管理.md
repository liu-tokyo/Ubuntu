## 家庭电脑批量管理

管理 14 台笔记本电脑就像管理一个小型机房。如果你一台一台去点，那不是“玩电脑”，那是被电脑玩。

要实现“一呼百应”，你需要一套**中央控制系统**。根据你的 Ubuntu + Windows 混合环境，我为你推荐三种由浅入深的方案：

------

### 1. 最简单：无界鼠标（Mouse Without Borders）

既然你 14 台电脑都在家里，可能有些是摆在一起的。

- **功能：** 它是微软 PowerToys 里的一个工具。
- **效果：** 你只需要一套键盘鼠标。当你鼠标滑出第一台电脑屏幕边缘，它就直接进入了第二台、第三台电脑。
- **一呼百应：** 它有一个“**所有电脑同步**”模式。你在一台电脑上输入一段代码或点击关机，**所有连接的电脑会同时执行相同的操作**。
- **适用：** 3-4 台笔记本摆在一张桌子上的实时操作。

------

### 2. 最极客：Ansible（自动化运维神器）

既然你有 Ubuntu 服务器，这是最推荐的**工业级**方案。Ansible 不需要你在 14 台客户端安装任何复杂的软件，它通过网络（SSH 或 WinRM）直接下达命令。

1. **在 Ubuntu 上安装 Ansible：** `sudo apt install ansible`
2. **配置控制：** 你写一个包含 14 台电脑 IP 地址的“清单”文件。
3. **一键操作：**
   - **批量关机：** `ansible all -m win_shell -a "shutdown /s /t 0"`
   - **批量备份：** 运行你之前写的备份脚本。
   - **批量更新：** 让所有 Windows 同时开始检查更新。

- **适用：** 已经在跑 GitLab 的你。你可以把 Ansible 的脚本（Playbooks）存在 GitLab 里，实现代码化管理电脑。

------

### 3. 最统一：MeshCentral（远程管理平台）

这是一个开源的、基于 Web 的远程管理平台，非常适合管理家里不同角落的 14 台设备。

1. **安装：** 在你的 Ubuntu 上用 Docker 跑一个 MeshCentral。
2. **部署：** 在 14 台电脑上分别安装一个小小的“代理程序（Agent）”。
3. **效果：** 你在任何一台电脑打开浏览器，登录你的 MeshCentral 页面，就能看到：
   - 14 台电脑的实时屏幕预览。
   - **批量发送指令：** 有个终端窗口，你输入一行命令，14 台电脑同时执行。
   - **文件分发：** 把一个游戏补丁同时推送到所有电脑上。

- **适用：** 电脑分布在不同房间，或者你想在沙发上用平板电脑管理所有设备。

------

### 💡 针对你 25H2 环境的“特别大招”：

在 Windows 11 25H2 上，我强烈建议你开启 **OpenSSH Server**（系统自带功能）：

1. 在 25H2 的设置里搜索“可选功能”，安装 **OpenSSH 服务器**。
2. 这样你就可以在 Ubuntu 终端里，直接通过命令进入任何一台笔记本：`ssh username@192.168.1.x`。

**想象一下这个画面：** 你坐在 Ubuntu 面前，输入一条指令，家里 14 台笔记本的屏幕同时亮起，开始自动从 Samba 下载最新的游戏包。这种“指挥千军万马”的感觉，才是玩 14 台电脑的巅峰体验！

## 自动备份脚本

既然你有 14 台电脑，一台一台手动备份肯定会让你“生事”累到头大。在 Windows 11 25H2 上，最专业且最简单的办法是使用 Windows 自带的 **Robocopy** 指令。

Robocopy（强大的文件复制工具）比普通的 `copy` 指令强在：它支持**增量备份**（只复制改动过的文件，速度极快）且非常稳定。

### 第一步：编写备份脚本

1. 在 Windows 桌面上点击右键，新建一个 **文本文档**。
2. 将名字改为 `daily_backup.bat`（注意后缀名要从 `.txt` 改为 `.bat`）。
3. 右键点击这个文件，选择“编辑”，贴入以下代码：

コード スニペット

```bat
@echo off
:: --- 配置部分 ---
:: 设置源文件夹路径（例如你的游戏存档文件夹）
set SOURCE_DIR="C:\Users\你的用户名\Documents\My Games"

:: 设置目标文件夹路径（Samba 映射后的盘符，假设是 Z 盘）
set DEST_DIR="Z:\Backup\GameSaves"

:: 设置日志存放路径
set LOG_FILE="C:\Users\你的用户名\Desktop\backup_log.txt"
:: ----------------

echo 正在开始备份... %date% %time%

:: Robocopy 参数解释：
:: /MIR : 镜像模式（增量备份，删除源端没有的文件）
:: /FFT : 兼容 Unix 文件系统的时间戳（对 Samba 非常重要）
:: /R:3 : 失败重试 3 次
:: /W:5 : 每次重试等待 5 秒
:: /MT:16 : 开启 16 线程并发，速度飞快

robocopy %SOURCE_DIR% %DEST_DIR% /MIR /FFT /R:3 /W:5 /MT:16 /LOG:%LOG_FILE% /NP

echo 备份完成！日志已保存至 %LOG_FILE%
pause
```

### 第二步：设置深夜自动运行（任务计划程序）

你不需要手动去点这个 `.bat` 文件，让 Windows 25H2 自动完成：

1. 点击开始菜单，搜索并打开 **任务计划程序 (Task Scheduler)**。
2. 在右侧点击 **“创建基本任务...”**。
3. **名称：** 输入 `Daily_Samba_Backup`。
4. **触发器：** 选择 **“每天”**。
5. **时间：** 设置为你睡觉的时间，比如 `03:00:00`。
6. **操作：** 选择 **“启动程序”**。
7. **程序或脚本：** 点击“浏览”，找到你刚才保存的那个 `daily_backup.bat`。
8. **完成：** 在点击完成前，勾选“**完成后打开属性对话框**”。
9. **关键设置（必做）：** 在属性窗口中，勾选 **“不管用户是否登录都要运行”** 和 **“使用最高权限运行”**。这样即使你电脑锁屏了，它也会准时干活。

------

### 第三步：针对 14 台电脑的“偷懒”技巧

既然你有 14 台笔记本，一台台设置任务计划太痛苦了。

- **脚本通用化：** 你可以把这个 `.bat` 脚本本身也放在 Ubuntu 的 Samba 盘里。
- **统一路径：** 每台笔记本都把 Samba 映射为 `Z:` 盘。
- **一键部署：** 在每台电脑上运行一次任务计划设置，以后你只需要在 Ubuntu 上修改那个 `.bat` 脚本里的内容，所有电脑都会按照新的规则执行。

------

### 💡 极客小贴士：

- **网络唤醒 (WOL)：** 如果你深夜备份时有些笔记本关机了，你甚至可以在 Ubuntu 上写个简单的 Python 脚本，在凌晨 2:50 通过网络把所有笔记本“唤醒”，备份完再让它们自动关机。
- **GitLab 联动：** 如果你备份的是非常精细的配置文件，你可以在 Ubuntu 端写个脚本，当 Samba 文件夹有变动时，自动 `git commit` 到你的 GitLab 仓库里，实现“双重保险”。
